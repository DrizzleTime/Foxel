# Create a folder

Click "语言" (Language) at the top and choose "English".
Click "Next". Type "Local" as the Mount Name and click "Next".
Type "samrivera" as the Username, "Sam Rivera" as the Full Name, "sam@example.com" as the Email and "Foxel-Test-2026" as both the Password and Confirm Password, then click "Finish Initialization".
Wait for the File Manager to load, then close the "Notices" dialog with its X button.

Verify it shows "This folder is empty".

Verify "Projects" is listed in the local folder.
